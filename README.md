# 90 Days AI Engineer Challenge

Welcome to my **90 Days AI Engineer Challenge**.

The goal of this repository is to become job-ready as a Python Backend Developer and AI Engineer by building real-world projects and learning industry-standard tools over the next 90 days.

- Build REST APIs
